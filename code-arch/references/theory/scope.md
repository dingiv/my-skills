# 作用域（Scope）

> **复杂需求不能一口气做完——必须拆。** 拆的依据是**作用域**：把状态机的全局作用域切成若干子作用域，把状态放进合适的作用域，以此把状态空间复杂度压回线性。

## 一句话

> **作用域 = 内存中划出的一块区域，有自己的状态、有自己的生命周期、和外部有明确的接口；程序 = 状态 + 作用域的管理。**

## 为什么需要作用域

- **端到端需求** = 用户直接给出的程序级需求（见 [anatomy.md](anatomy.md)）
- **复杂需求** = 多条端到端链路 + 多种状态 + 多个相互依赖的子系统
- 在一个全局作用域里管理所有状态 = 状态空间爆炸 = 时序错位 + 维护噩梦

**作用域的核心作用**：

1. **空间隔离**——每个作用域有自己的状态集合，外部不能直接访问。
2. **生命周期独立**——每个作用域的展开 / 闭合与其他作用域正交。
3. **接口稳定**——作用域对外只暴露固定接口，内部状态变化不影响外部。
4. **降低状态空间复杂度**——把 N 个全局状态的问题切成 K 个子问题，每个子问题只关心自己作用域内的状态。

## 父子作用域

作用域之间有三种关系：

| 关系 | 含义 | 例子 |
| --- | --- | --- |
| **父子** | 父作用域嵌套子作用域；父依赖子 | 函数调用、模块嵌套、类成员 |
| **兄弟** | 同一父作用域下的多个子作用域；不直接依赖 | 一个模块里的多个子模块 |
| **全局 - 局部** | 全局作用域 = 所有局部作用域的父代 | main 入口 |

**核心约束**：

- **父依赖子**——父作用域要能工作，子作用域必须先就绪（这是 [timing.md](timing.md) 第 1 条「依赖前向包含」的具体形态）
- **兄弟通信走父**——兄弟作用域之间不能直接通信，必须经过共享的父作用域（避免循环依赖）
- **禁止循环依赖**——A 依赖 B、B 依赖 A = 划分错误。纠正：把冲突内容拆到一个新的独立作用域里

## 作用域层级

不同语言提供不同的作用域抽象，从大到小：

```
模块作用域（package / crate / namespace）
  └─ 类作用域（class / struct）
      └─ 函数作用域（function / method）
          └─ 块作用域（block / closure）
```

每一层都可以独立 `init` / `destroy`，这是 [workflow.md 第 2.4 步](workflow.md)「能独立生命周期才能拆」的判据。

## 全局 vs 局部

| 维度 | 全局作用域 | 局部作用域 |
| --- | --- | --- |
| 实例数 | 一次程序运行**只能展开一次** | 可以**展开多次**（每次都是新实例） |
| 生命周期 | 程序启动 → 结束 | 函数调用 → 返回 |
| 适合存放 | 不可变常量、纯函数、单例基础设施 | 局部状态、临时变量、可变状态 |
| 反模式 | 大量可变全局状态 | 把可变状态塞进全局 |

**全局作用域的边界**：

- 可以放：日志、配置、单例进程级资源
- **不能**放：需要反复创建 / 销毁的可变状态——这些必须放进局部作用域
- 必须放时，参考 [ts-style 规则 8「受控的全局状态」](https://example.com/ts-style) 的 4 钩子（init / get / set / destroy）+ 唯一 Owner 模式

## 状态与生命周期

作用域有生命周期，状态也有生命周期。两者必须**绑定**：

| 状态类型 | 创建 | 修改 | 销毁 |
| --- | --- | --- | --- |
| 内存变量 | `let x = ...` | `x = ...` | 离开作用域（Drop） |
| IO 资源 | `open()` / `connect()` | `read()` / `write()` | `close()` |
| 后台任务 | `spawn()` | 任务运行中 | `join()` / `abort()` |

**所有权规则**：

- 状态在哪里创建，**最近一级的作用域**就是其所有者
- 关闭作用域时，必须关闭其所有状态资源
- 可以把所有权**转移**给外部作用域（move 语义），转移后作用域不再负责销毁

## 自检

- [ ] 程序没有把所有状态塞在全局作用域？
- [ ] 每个作用域都明确：哪些状态属于自己、对外暴露什么接口、生命周期怎么走？
- [ ] 父子作用域的依赖是单向的（父依赖子）？
- [ ] 兄弟作用域之间没有直接通信（必须经过共享父）？
- [ ] 没有循环依赖？
- [ ] 可变全局状态是受控的、4 钩子齐全的（init / get / set / destroy）？

任何一项不满足，去查 [典型反模式](anti-patterns.md) 和 [自查清单](self-check.md)。

> **作用域 = 用空间隔离换状态空间复杂度的下降；作用域是 code_arch 第 2.4 步「空间复杂度优化」的具体形态。**
